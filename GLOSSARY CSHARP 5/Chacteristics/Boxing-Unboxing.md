
# Managed Heap
Which wraps the value inside of an System Object instance, also called Boxing
```c#
  int number = 2389;
  object item = number; // Boxes number
  Console.WriteLine($"Boxes {item}");

  item = 231;
  number = (int)item; // unboxing 
  Console.WriteLine($"unboxing {number}");
```
