# The Is Operator
This modifier is use to match an expression against a property pattern nested constant and relational patterns
```c#
int number = 34;
object boxed = number;
int other = 45;
if (boxed is int n && other is int o) {
    Console.WriteLine(n + o);
}

int draw = 60;
string fav = "blue";

if (draw is int pick) {
    Console.WriteLine(draw + pick);
    if (fav is string color) {
        Console.WriteLine(fav + color);
    }
}
```
