
# OrderBy() Method 
That can be used in a foreach loop and the `Console.Write()` method displays in the terminal vertically 
```c#
class ExtensionMethods2
{

    static void Main()
    {
        int[] num = [10, 45, 15, 39, 21, 26];
        var result = num.OrderBy(g => g);
        foreach (var i in result)
        {
            Console.Write(i + " ");
        }
    }
}
//Output: 10 15 21 26 39 45
```
